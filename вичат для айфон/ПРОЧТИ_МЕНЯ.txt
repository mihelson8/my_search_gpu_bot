# WeChat (微信) на iPhone — для пользователя из России

Папка: **вичат для айфон**

## Как открыть инструкцию

Откройте файл **КАК_СКАЧАТЬ_И_ЗАРЕГИСТРИРОВАТЬСЯ.html** двойным щелчком (откроется в браузере). Внутри — все шаги с фото:

1. Выключить VPN
2. Скачать WeChat из App Store (шаги 1–8)
3. Регистрация с номером +7 (шаги 9–15)
4. QR-проверка другом, если WeChat её попросит
5. Запасной вход через Apple

Фото лежат в папке `фото/`.

Официальная ссылка App Store (Россия):  
https://apps.apple.com/ru/app/wechat/id414478124
