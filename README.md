Мощный переводчик и словарь технических и IT-терминов на **китайском (中文)**, **английском (English)** и **русском (Русский)** языках с поддержкой **Telegram-бота**, **консольного CLI-интерфейса** и **Python API**.

## 🚗 Автономера Seetong — база «Свой / Чужой»

**Да, это возможно.** Программа Seetong (Sitong / Topsee) не отдаёт «голый» видеопоток в другие приложения, если камера смотрит через облако. Поэтому клиент на Windows снимает **окно Seetong скриншотами**, пока на экране открыт живой просмотр камеры, читает госномер и сверяет его с локальной базой.

Что умеет модуль:

1. Скриншоты окна **Seetong Lite Client** (окно не сворачивайте, канал с камерой на парковку, например CH_02).
2. Запасные источники: весь экран, **RTSP** (`rtsp://admin:123456@IP:554/mpeg4` для камер Topsee в локальной сети), HTTP-снимок (`http://IP/snapshot.cgi`), файл.
3. Распознавание **российских номеров типа 1**: `А 000 АА | 00` (буква + 3 цифры + 2 буквы и регион 2–3 цифры справа, как на табличке). На кадре сначала ищется **силуэт автомобиля**, двор, небо и надписи камеры отсекаются — номер читается только на машине.
4. База **СВОЙ / ЧУЖОЙ**, журнал проездов и скриншоты в `anpr_data/`.
5. Если OCR не уверен — номер можно ввести вручную по кадру.

### Запуск на Windows (тот компьютер, где открыт Seetong)

1. Откройте **Seetong Lite Client** на вкладке Main View с картинкой камеры.
2. Двойной клик по **`START_ANPR.bat`** (при первом запуске поставит OpenCV, mss, RapidOCR и ярлык **Автономера Seetong** на рабочий стол). Дальше программу можно открывать с рабочего стола. Если ярлыка нет — один раз запустите **`DESKTOP_SHORTCUT_ANPR.bat`**.
3. В программе нажмите **Старт**. Источник по умолчанию — окно `Seetong Lite Client`.
4. Во вкладке **База Свой / Чужой** добавьте свои машины.

**Другой компьютер в локальной сети с камерой:** скачайте ZIP этой ветки, поставьте Python 3 (галочка Add to PATH), в папке проекта `python -m pip install -r requirements-anpr.txt`, затем `python anpr_gui.py`. Кнопка **Камера / IP** — введите IP, логин `admin`, пароль (часто `123456`). Сначала HTTP-снимок, если не выйдет — RTSP: `rtsp://admin:ПАРОЛЬ@IP:554/mpeg4`.

```bash
pip install -r requirements-anpr.txt
python anpr_gui.py
python -m anpr add А123ВС777 --name "Моя машина" --category свой
python -m anpr list
```

Ограничения: облачный агент Cursor **не видит** вашу камеру и Seetong — программа должна работать на вашем ПК. Точность OCR зависит от ракурса, света и размера номера в кадре; для лучшего результата направьте камеру на зону ворот и обрежьте меню Seetong в настройках.

## 🐱 Ветеринарный визуальный триаж кошек (`vet_bot.py`)

Telegram-бот, который по **фотографиям и коротким видео** оценивает, насколько срочно кошке нужен ветеринарный врач, показывает список вероятных состояний и справочные данные о препаратах.

**Чего бот принципиально не делает:** он не ставит диагноз и не назначает лечение. По изображению достоверно определить заболевание невозможно, поэтому бот работает как инструмент сортировки (триажа): считает срочность, объясняет, какие признаки важны, и готовит структурированную информацию для приёма у врача. Дозировки в справочнике — литературные значения для разговора с врачом, а не назначение.

### Что умеет

1. **Разбор фото.** Проверка качества кадра (разрешение, яркость, пересвет, резкость по центральному фрагменту в исходном разрешении) и цветовые подсказки: покраснение, желтушность слизистых, бледность, тёмный ушной налёт, залысины, выделения. Альбом из нескольких фото разбирается целиком, результат сводится в одно сообщение.
2. **Разбор коротких видео** (до 60 секунд, до 20 МБ — лимит Telegram Bot API). Кадры извлекаются через `ffmpeg`, подсказки агрегируются по кадрам, дополнительно считаются метрики движения: средняя активность, пиковая амплитуда и ритмичность. Это то, что не видно на фото: хромота, тряска головой, расчёсывание, характер дыхания, шаткость походки.
3. **Опросник по 10 зонам тела** (глаза, уши, кожа и шерсть, рот, дыхание, ЖКТ, мочеиспускание, неврология, опора и движение, общее состояние) — 48 визуальных признаков в виде инлайн-чеклиста с переключателями `⬜ / ✅`. У каждого признака есть кнопка `❓` с подсказкой, как именно снять этот признак на камеру.
4. **Оценка срочности** в четырёх уровнях: плановый визит, визит в течение 24–48 часов, срочно сегодня, экстренно немедленно. Подтверждение угрожающего признака (дыхание открытым ртом, натуживание в лотке без мочи, судороги, бледные или жёлтые слизистые) сразу выдаёт отдельное предупреждение, не дожидаясь конца опроса. Учитываются пол, возраст и вес: у котов закупорка уретры развивается быстрее, котята и пожилые кошки декомпенсируются раньше.
5. **20 профилей состояний** с латинскими названиями, обследованиями, которые обычно назначают в клинике, и допустимыми действиями до приёма.
6. **Справочник из 18 препаратов** по группам: показания, формы выпуска, литературные дозировки, особенности у кошек, противопоказания, рецептурность.
7. **Список опасных для кошек веществ** (парацетамол, ибупрофен, перметрин, эфирные масла, лилии) и памятка первой помощи.

### Запуск: пошагово от нуля до работающего бота

**Шаг 1. Создать бота в Telegram.** Напишите [@BotFather](https://t.me/BotFather), команда `/newbot`, задайте имя и логин (логин должен заканчиваться на `bot`, например `my_cat_triage_bot`). В ответ придёт токен вида `1234567890:AAE...` — это пароль от бота, никому его не показывайте.

**Шаг 2. Заполнить описание бота там же, в BotFather.** Это важно с точки зрения безопасности пользователей: человек должен видеть ограничения до первого сообщения.

- `/setdescription` — «Предварительная оценка состояния кошки по фото и видео. Не заменяет ветеринарного врача и не назначает лечение.»
- `/setabouttext` — «Визуальный триаж для кошек: срочность визита, вероятные состояния, справочник препаратов.»
- `/setuserpic` — картинка, `/setcommands` бот выставляет сам при старте.

**Шаг 3а. Запуск на Windows** (для проверки и для домашнего использования):

1. Скачайте папку проекта и распакуйте её (не запускайте из архива WinRAR).
2. Установите [Python 3](https://www.python.org/downloads/) с галочкой **Add python.exe to PATH**.
3. По желанию поставьте [ffmpeg](https://www.gyan.dev/ffmpeg/builds/) и добавьте его папку `bin` в PATH — без него работают только фото.
4. Двойной клик по **`START_VET_BOT.bat`**. При первом запуске он поставит зависимости и попросит вставить токен, сохранив его в `.env`.
5. Окно консоли не закрывайте: пока оно открыто, бот отвечает. Закрыли окно — бот замолчал.

**Шаг 3б. Запуск на Linux или macOS:**

```bash
pip install -r requirements.txt          # нужен Pillow
sudo apt install ffmpeg                  # для разбора видео

echo 'VET_BOT_TOKEN=1234567890:AAE...' > .env
python3 vet_bot.py
```

**Шаг 4. Проверить бота самому, до реальных пользователей.** Откройте бота в Telegram, нажмите `/start` и пройдите чеклист:

- фото глаза или уха — приходит разбор кадра с кнопками подтверждения;
- альбом из 3 фото — приходит одно сообщение, счётчик обработанных фото растёт;
- видео 10–20 секунд — приходит разбор с метриками движения;
- видео на 2 минуты — бот отказывается и объясняет лимиты;
- `🩺 Симптомы по зонам` → «Дыхание открытым ртом» — сразу приходит красное предупреждение;
- `📋 Мой отчёт` — есть срочность, состояния с процентами и дисклеймер;
- `💊 Справочник лекарств` — карточка препарата с дозировкой и противопоказаниями;
- `/reset` — разбор очищается.

**Шаг 5. Включить круглосуточную работу.** Опрос Telegram в боте уже сделан непрерывным: длинное соединение на 30 секунд вместо частых запросов, автоматический перезапуск после сбоя с нарастающей паузой и самопинг собственного адреса каждые 45 секунд, чтобы бесплатный хостинг не усыплял сервис. Сообщения, пришедшие во время простоя, не теряются — Telegram хранит их сутки, и бот разбирает их после подъёма.

Но ни один код не спасёт от выключенного компьютера. Пока бот запущен на домашней машине, он молчит, когда та спит или закрыто окно консоли. Поэтому либо отключите в Windows переход в спящий режим, либо перенесите бота на хостинг:

```bash
# Docker на любом VPS
docker build -f Dockerfile.vetbot -t vet-triage-bot .
docker run -d --name vet-bot --restart unless-stopped \
  -e VET_BOT_TOKEN="1234567890:AAE..." -p 10000:10000 vet-triage-bot
```

Для Render в репозитории лежит готовый блюпринт `render.yaml`: в панели Render выберите **New → Blueprint**, укажите этот репозиторий, и он сам создаст Web Service из `Dockerfile.vetbot`, спросив только токен. Если делать вручную: создайте Web Service с Dockerfile `Dockerfile.vetbot`, добавьте переменную окружения `VET_BOT_TOKEN` и оставьте порт `10000` — встроенный health-check сервер отвечает на пинги. Render сам подставит `RENDER_EXTERNAL_HOSTNAME`, и самопинг подхватит его автоматически; на других хостингах задайте адрес вручную через `VET_BOT_PUBLIC_URL`. Дополнительно в репозитории есть workflow `.github/workflows/keep-alive-vet-bot.yml`, который пингует сервис извне раз в 10 минут: чтобы он заработал, добавьте переменную `VET_BOT_URL` в Settings → Secrets and variables → Actions → Variables. На своём сервере вместо Docker подойдёт systemd-юнит с `Restart=always`.

На Windows `START_VET_BOT.bat` перезапускает бота сам, если процесс упал: он различает штатную остановку по Ctrl+C, ошибку токена (тогда просто сообщает о ней) и аварийное завершение, после которого ждёт 10 секунд и стартует заново.

**Шаг 6. Дальше — точность.** Эвристики по цвету дают только грубые подсказки, и это честное ограничение текущей версии. Чтобы получить настоящее распознавание, нужен размеченный ветеринарами набор фотографий: снимки по зонам тела с подтверждённым в клинике заключением, минимум несколько сотен примеров на каждый признак. На нём дообучается EfficientNet или ViT, и модель подключается через `set_classifier` (см. ниже) без переписывания бота. До этого момента бот остаётся инструментом сортировки, а не диагностики.

Без `ffmpeg` бот продолжает работать: видео будет отклоняться с просьбой прислать фотографии.

### Как подключить обученную модель

Эвристики по цвету дают только грубые подсказки. Для настоящего распознавания (дообученный EfficientNet, ViT или ONNX-модель) в `vetcare/vision.py` есть протокол `SignClassifier` — достаточно объекта с методом `predict(image_bytes) -> [(код_признака, уверенность)]`:

```python
from vetcare.vision import set_classifier

class MyModel:
    def predict(self, image_bytes):
        return [("eye_cornea_cloudy", 0.87)]

set_classifier(MyModel())
```

Предсказания с уверенностью выше 0.35 попадают в подсказки наравне с эвристиками и участвуют в оценке. Ошибка внутри модели не ломает бота: она логируется, и разбор продолжается на эвристиках. Качество такой модели полностью зависит от набора фотографий, размеченного ветеринарами.
