# 🇨🇳 🇬🇧 🇷🇺 Переводчик технических терминов (Chinese - English - Russian)

Мощный переводчик и словарь технических и IT-терминов на **китайском (中文)**, **английском (English)** и **русском (Русский)** языках с поддержкой **Telegram-бота**, **консольного CLI-интерфейса** и **Python API**.

---

## 🌟 Основные возможности

1. **🌐 Трехъязычный технический словарь:**
   - 🇬🇧 **English:** Общепринятая международная терминология.
   - 🇨🇳 **中文 (Китайский):** Упрощенные и традиционные иероглифы + транскрипция **Пиньинь (Pinyin)** с тонами.
   - 🇷🇺 **Русский:** Общепринятые переводы и русскоязычные термины.
   - Подробные определения на 3 языках, примеры употребления в предложениях, синонимы, аббревиатуры и связанные понятия.

2. **📁 Тематические категории:**
   - 💬 **Повседневное общение и этикет** (Приветствия, благодарность, извинения, вежливые фразы, согласие...)
   - ✈️ **Путешествия, город и транспорт** (Метро, такси Didi, скоростной поезд, отель, как спросить дорогу...)
   - 🍜 **Еда, рестораны и покупки** (Заказ блюд, меню, счет, торг, оплата через WeChat Pay и Alipay...)
   - 💼 **Работа, офис и деловое общение** (Совещания, созвоны, дедлайны, удаленка, командное сотрудничество...)
   - 🤖 **Искусственный интеллект и ML** (Deep Learning, LLM, Transformer, RAG, Tokenization, Embedding...)
   - 💻 **Разработка ПО и программирование** (Compiler, OOP, Multithreading, Asynchronous, Memory Leak...)
   - ⚙️ **Аппаратное обеспечение (Железо)** (CPU, GPU, VRAM, RAM, SSD, Microarchitecture...)
   - 🌐 **Компьютерные сети и протоколы** (TCP/IP, DNS, HTTP/HTTPS, REST API, Load Balancer...)
   - 🗄️ **Базы данных и хранилища** (RDBMS, NoSQL, ACID, Sharding, Replication, Vector DB...)
   - ☁️ **Облачные технологии и DevOps** (Docker, Kubernetes, CI/CD, Microservices...)
   - 🔒 **Информационная безопасность** (Encryption, Hash Function, Authentication, Authorization, DDoS...)
   - 📊 **Алгоритмы и структуры данных** (Binary Search Tree, Hash Table, Dynamic Programming...)
   - 🖥️ **Операционные системы** (Kernel, Virtual Memory, Deadlock, Mutex, System Call...)

   - Поиск в любом направлении: RU ↔ ZH ↔ EN ↔ BUA (Бурятский).

   - Поиск по синонимам и аббревиатурам (AI, LLM, K8s, DP, OOP, RAG, GPU и др.).
   - Автоматический онлайн-переводчик произвольного текста и предложений (включая бурятский перевод).

4. **🤖 Интерактивный Telegram-бот:**
   - 🔤 **Кнопки языков в главном меню:** `[🇷🇺 Русский]`, `[🇺🇸 American English]`, `[🇨🇳 Путунхуа]`, `[🇭🇰 Кантонский / Байхуа]`, `[🔵 Буряад хэлэн (Бурятский)]`.

   - 100% защита от блокировок: работа через официальные вебхуки без неофициальных юзер-ботов.
   - Мгновенный синхронный перевод в WeChat с пиньинем и транскрипцией.

6. **📱 WeChat Mini Program (Мини-программа 微信小程序):**

```python
import asyncio
from translator import TechTranslator, TerminologyEngine, Language

async def main():
    translator = TechTranslator()
    
    # Поиск термина
    result = await translator.translate("transformer")
    if result.direct_match:
        term = result.direct_match
        print(f"EN: {term.en}")
        print(f"ZH: {term.zh} ({term.pinyin})")
        print(f"RU: {term.ru}")
        print(f"Определение (RU): {term.definition_ru}")

asyncio.run(main())
```

## 💼 CCTV & China Cargo Business Suite (Пульт управления микробизнесом)

Автономная программа для ПК (Windows) для ведения базы клиентов (с 2016 года), автоматической генерации персонализированных офферов по модернизации систем видеонаблюдения, предложений по доставке товаров из Китая/Гонконга, работы с партнерами (прорабы/электрики) и экспресс-калькуляторов.

### 🚀 Быстрый запуск на Windows:
1. Запустите двойным кликом файл **`START_APP_WINDOWS.bat`** (или `START_GUI_DESKTOP.bat`).
2. Программа откроется в вашем браузере по адресу `http://localhost:8765` или в отдельном окне.
3. Доступны разделы:
   - **База клиентов:** фильтрация (Физлица / Юрлица / Партнеры), статусы в воронке, интерес к Китаю.
   - **План действий на 7 дней:** интерактивный чек-лист со статусами выполнения.
   - **Шаблоны офферов:** генерация и персонализация текстов для WhatsApp/Telegram в 1 клик.
   - **Калькуляторы:** расчет модернизации видеонаблюдения и себестоимости доставки карго из Китая.
   - **Импорт/Экспорт:** загрузка базы из Excel/CSV и выгрузка отчетов.
   - **Автономера:** кнопка «Автономера Seetong» открывает программу чтения номеров.

## 🚗 Автономера Seetong — база «Свой / Чужой»

**Да, это возможно.** Программа Seetong (Sitong / Topsee) не отдаёт «голый» видеопоток в другие приложения, если камера смотрит через облако. Поэтому клиент на Windows снимает **окно Seetong скриншотами**, пока на экране открыт живой просмотр камеры, читает госномер и сверяет его с локальной базой.

Что умеет модуль:

1. Скриншоты окна **Seetong Lite Client** (окно не сворачивайте, канал с камерой на парковку, например CH_02).
2. Запасные источники: весь экран, **RTSP** (`rtsp://admin:123456@IP:554/mpeg4` для камер Topsee в локальной сети), HTTP-снимок (`http://IP/snapshot.cgi`), файл.
3. Распознавание **российских номеров типа 1**: `А 000 АА | 00` (буква + 3 цифры + 2 буквы и регион 2–3 цифры справа, как на табличке). В момент обнаружения на кадре рисуется **форма авто** (контур) и **рамка** вокруг машины; двор и небо затемняются. Номер читается только на машине.
4. База **СВОЙ / ЧУЖОЙ**, журнал проездов и скриншоты в `anpr_data/`.
5. Если OCR не уверен — номер можно ввести вручную по кадру.

### Запуск на Windows (тот компьютер, где открыт Seetong)

1. Закройте WinRAR. Распакуйте ZIP в любую папку.
2. Двойной клик по **`START_ANPR.bat`** (или `FIX_AND_CLEAN.bat`). Скрипт:
   - ставит программу в **`D:\AvtonomeraSeetong`**
   - создаёт ярлык **Автономера Seetong** без чёрного окна cmd (`pythonw.exe`)
   - удаляет лишние копии `my_search_gpu_bot*` с Desktop / Downloads / `D:\`
   - открывает окно справа, чтобы Seetong остался слева
3. Откройте **Seetong Lite Client** на Main View. Съёмка начнётся сама. Нужен номер вида `А 000 АА | 00`.

Дальше достаточно ярлыка на рабочем столе. Папка снимков только одна: `C:\Program Files (x86)\Seetong\pi`. RapidOCR на Python 3.14 может не встать — это нормально: сначала ставятся opencv, Pillow, mss, numpy.

**Другой компьютер в локальной сети с камерой:** скачайте ZIP этой ветки, поставьте Python 3 (галочка Add to PATH), в папке проекта `python -m pip install -r requirements-anpr.txt`, затем `python anpr_gui.py`. Кнопка **Камера / IP** — введите IP, логин `admin`, пароль (часто `123456`). Сначала HTTP-снимок, если не выйдет — RTSP: `rtsp://admin:ПАРОЛЬ@IP:554/mpeg4`.

```bash
pip install -r requirements-anpr.txt
python anpr_gui.py
python -m anpr add А123ВС777 --name "Моя машина" --category свой
python -m anpr list
```

Ограничения: облачный агент Cursor **не видит** вашу камеру и Seetong — программа должна работать на вашем ПК. Точность OCR зависит от ракурса, света и размера номера в кадре; для лучшего результата направьте камеру на зону ворот и обрежьте меню Seetong в настройках.
